# 운동·러닝 퀴즈 게임

## 프로젝트 개요

Python으로 만든 터미널 퀴즈 게임입니다. 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 최고 점수 확인을 선택할 수 있습니다. 추가한 퀴즈와 최고 점수는 JSON 파일에 저장되어 프로그램을 종료하고 다시 실행해도 유지됩니다.

## 퀴즈 주제와 선정 이유

운동과 러닝을 주제로 선택했습니다. 달리기, 마라톤, 운동 동작처럼 익숙한 내용을 문제로 만들면 Python의 입력·출력, 조건문, 반복문, 클래스, 파일 저장 기능을 연습하는 데 집중할 수 있기 때문입니다. 기본 퀴즈 5개가 포함되어 있습니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 외부 라이브러리는 사용하지 않습니다.

프로젝트 폴더에서 다음 명령어로 실행합니다.

```bash
python3 main.py
```

메뉴 번호는 1~5 중에서 선택합니다. 퀴즈의 정답 번호와 새 퀴즈를 등록할 때의 정답 번호는 1~4 중에서 입력합니다.

## 기능 목록

- 퀴즈 풀기 및 문제별 정답·오답 표시
- 모든 문제를 푼 뒤 정답 개수 표시
- 문제, 선택지 4개, 정답 번호를 입력해 새 퀴즈 등록
- 등록된 퀴즈 목록 확인
- 최고 정답 개수 확인
- 빈 입력, 숫자가 아닌 입력, 범위 밖 번호에 대한 재입력 안내
- `Ctrl+C` 또는 입력 종료 시 안내 메시지 출력 후 안전하게 종료
- 데이터 파일이 없으면 기본 퀴즈로 시작
- 데이터 파일을 읽을 수 없거나 손상됐으면 안내 후 기본 퀴즈로 시작

## 파일 구조

```text
quiz-game/
├── main.py       # Quiz와 QuizGame 클래스 및 프로그램 실행 코드
├── README.md     # 프로젝트 설명과 실행 방법
├── .gitignore    # Git 추적 제외 설정
└── state.json    # 실행 중 생성되는 퀴즈와 최고 점수 데이터
```

## 데이터 파일 설명

`state.json`은 프로젝트 루트에 저장됩니다. 파일을 읽고 쓸 때 UTF-8 인코딩을 사용합니다.

- `quizzes`는 퀴즈 목록입니다.
- 각 퀴즈의 `question`은 문제, `choices`는 선택지 4개, `answer`는 1~4의 정답 번호입니다.
- `best_score`는 한 게임에서 맞힌 최고 정답 개수입니다. `null`이면 아직 완료한 게임이 없다는 뜻입니다.

JSON 데이터의 구조는 다음과 같습니다.

```json
{
  "quizzes": [
    {
      "question": "달리기를 시작하기 전에 하면 좋은 것은?",
      "choices": ["준비운동", "바로 전력 질주", "움직이지 않기", "신발 벗기"],
      "answer": 1
    }
  ],
  "best_score": null
}
```

`state.json`은 개인 실행 데이터이므로 `.gitignore`에서 Git 추적 대상에서 제외합니다. GitHub 저장소를 복제한 뒤 처음 실행하면 기본 퀴즈 5개로 시작합니다.
